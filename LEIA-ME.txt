PastaFácil - Versão inicial 1.0

1. Instale Python 3 no Windows se ainda não estiver instalado.
2. Execute INICIAR.bat para abrir o aplicativo.
3. Cole no campo principal as células copiadas do Excel (Ctrl+C / Ctrl+V).
4. Marque ou desmarque a opção de cabeçalho e clique em Ler colunas.
5. Use Subir, Descer, Remover e Adicionar para definir a hierarquia.
6. Escolha uma pasta de destino já existente.
7. Clique em Atualizar prévia e confira a estrutura.
8. Clique em Criar pastas e confirme.

Para gerar um .exe no Windows com Python instalado, execute GERAR_EXE.bat.
O executável ficará na pasta dist. A compilação deve ser feita no Windows.

Segurança: não remove pastas ou arquivos. Nomes inválidos do Windows são rejeitados.
Linhas com campos vazios nas colunas selecionadas devem ser corrigidas.
